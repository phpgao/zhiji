Quick Start

极速安装上手

支持主流浏览器扩展或 Tampermonkey 油猴脚本，只需 1 分钟即可开启采集。

Chrome 扩展安装 (MV3)

支持 Chrome / Edge / Brave / Arc 等基于 Chromium 的现代浏览器。

  1. 前往 Releases 下载 zhiji-chrome.zip 并在本地解压；
  2. 在浏览器地址栏打开 chrome://extensions/；
  3. 开启右上角的 「开发者模式」 开关；
  4. 点击左上角 「加载已解压的扩展程序」，选择解压出的文件夹即可。
Chrome 商店一键安装 ↗ 下载离线 ZIP 安装包

Tampermonkey 油猴脚本

适合已安装 Tampermonkey / ScriptCat / Violentmonkey 的用户。

  1. 确认浏览器已安装油猴扩展（Tampermonkey）；
  2. 点击下方安装按钮，浏览器将自动弹出脚本安装确认窗口；
  3. 点击 「安装」 确认；
  4. 打开任意知乎回答或专栏页面刷新，右下角即刻出现知集悬浮球。

Integration

Obsidian 原生直连，零插件与 Token 门槛

基于 Obsidian 官方原生 URI 协议（obsidian://new），无需安装任何第三方插件或申请密钥。

  1. 打开知集设置面板
    在知乎页面点击知集悬浮胶囊右侧的 「⚙️ 设置」按钮（或浏览器右上角插件图标）。
  2. 填写知识库名称 (Vault)
    只需填入您正在使用的 Obsidian 仓库名（例如 MyNotes），并可选填写归档子文件夹（例如 zhihu/）：
    Obsidian 仓库名 (Vault): MyNotes （必填，对应你的 Obsidian 库名）
    保存文件夹 (Folder): zhihu/ （选填，留空则存入根目录）
  3. 点击「存入 Obsidian」一键写入
    点击后浏览器将直接唤起本地 Obsidian，以高保真 Markdown 格式瞬间新建笔记，自动携带完整 Frontmatter 元数据！
FAQ

常见问题解答

Q: 导出的 Markdown 文件包含哪些元数据？

每篇导出的文档顶部均包含标准的 YAML Frontmatter，涵盖标题（title）、作者（author）、原文直链（url）、采集时间（date）、知乎标签（tags）以及点赞数（upvotes）等结构化信息。

Q: 为什么专栏文章能完全去除无关推荐内容？

知集深度适配了知乎专栏真实 DOM 树，将作用域严格锚定在 <article class="Post-Main"> 容器内，彻底剔除了推荐阅读、热搜词、侧边栏等与正文无关的外层杂质。

Q: 采集评论需要很长时间吗？

知集默认按当前最佳排序平滑滚动抓取评论，抓取速度极快（通常 1~2 秒内抓完数十条）。您也可以在设置面板中自定义最大抓取评论数（支持 0~500 条），若设为 0 则直接跳过评论。

Q: 扩展会上传我的知乎账号或浏览数据吗？

绝无可能。知集 100% 运行于您的浏览器本地沙箱中，零远程代码、零分析打点、零隐私追踪，所有数据与图片直接在您的本地内存与磁盘中流转，代码已完全开源以供审查。
